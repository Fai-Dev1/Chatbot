# Stage 1: Basic Chatbot with Gemini AI

![AI Web App Roadmap](image.jpg)

A basic interactive chatbot built using **Streamlit** and powered by **Google Gemini AI**. In this stage, the chatbot runs entirely on the frontend, where Streamlit directly communicates with the Gemini API to process user messages.

## 🚀 How to Get Started

1. **Set Up Environment Variables:**
   Create a `.env` file in the root directory and add your API key:
   ```env
   GEMINI_API_KEY=YOUR-GEMINI-API-KEY

   Install Dependencies:
   pip install -r requirements.txt

   Run the Chatbot:
   streamlit run chatbot.py
